PRECISION Human Pain Network

npokb · InterLex Organization

The PRECISION Human Pain Network is a community of researchers building standardized cell type models for peripheral sensory neurons. By integrating nomenclature from multiple published sources and species, the network provides a shared framework for classifying, comparing, and annotating pain-related neuron types — enabling reproducible research and cross-study alignment across the pain neuroscience community.
