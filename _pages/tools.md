## NervoSensus

Interactive cell type visualization for peripheral sensory neurons. Explore
cluster relationships across sources, lineage views showing nomenclature
mappings, and per-cell phenotype detail panels.

- **Cluster view** — see how cell types from different papers relate by shared
  markers, with filtering by source, species, fiber type, and modality
- **Lineage view** — trace nomenclature mappings between the CSA consensus
  types and individual paper cell types
- **Cell detail** — full phenotype card for any cell type, with links to
  InterLex and source publications

[Launch NervoSensus](https://devservosensus.netlify.app/){: .btn .btn--primary .btn--large}

## InterLex Ontology Browser

Browse the full PRECISION cell type ontology on InterLex. Each cell type is
identified by a stable `npokb:` CURIE and annotated with markers, anatomical
locations, species, and literature citations using Neuron Phenotype Ontology
(NPO) predicates.

[Browse Ontology](https://interlex.dev.metacell.us/precision/ontology/precision){: .btn .btn--primary .btn--large}

## PRECISION Dashboard (SPARC)

Search gene expression patterns across PRECISION cell types on the SPARC
portal. Enter a gene symbol to see which cell types express it and how
expression varies across sources and species.

[Open Dashboard](https://sparc.science/apps/precision-dashboard){: .btn .btn--primary .btn--large}
